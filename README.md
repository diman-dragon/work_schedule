# Рабочий график

Веб-приложение для учёта рабочих смен: календарь с почасовым доходом,
статистика, тепловая карта загруженности, печатный табель и синхронизация
между устройствами через Google Диск. Работает прямо в браузере, без
установки и без сервера — все данные хранятся локально на устройстве.

## Возможности

**Календарь смен**
- Помесячный вид с переключением стрелками, клавишами ← → и свайпом на телефоне
- Быстрый переход «Сегодня»
- Ввод начала/конца смены, автобуса и маршрута для каждого дня
- Поддержка ночных смен, переходящих через полночь
- Подстановка часто используемых пар время начала–конца в один клик
- Фото графика смен (расписание по машинам/водителям) можно прикрепить к
  конкретному дню — приходит на пять рабочих дней и выходные и иногда
  меняется, теперь его удобно держать под рукой прямо в приложении
- Тепловая карта дней по заработку, в духе GitHub-календаря активности

**Статистика**
- Часы и заработок по месяцам, накопительный итог, сравнение месяц к месяцу
- Разбивка по дням недели, по времени начала смены, по длительности
- Топ-5 самых доходных смен, недельный тренд
- Статистика по автобусам и маршрутам
- Интерактивные графики (Chart.js)

**Данные**
- Автосохранение в этом браузере — ничего вводить заново не нужно
- Экспорт и импорт JSON, экспорт в CSV (открывается в Excel)
- Полноценный печатный табель формата A4
- Ручной и автоматический локальный бэкап (перед импортом и очисткой данных)
- Настраиваемая ставка (дин./ч) — применяется к новым и изменённым сменам,
  исторические значения не пересчитываются задним числом

**Синхронизация**
- Синхронизация между устройствами через собственный файл на Google Диске
- Данные шифруются на стороне браузера перед отправкой в облако — доступ к
  ним есть только у того, кто знает пароль
- Показывает дату и время последней успешной синхронизации

**Оформление**
- Тёмная и светлая тема
- Стилистика в духе Fluent Design (Windows 11): Mica-поверхности, единая
  шкала скруглений и теней, системная типографика
- Адаптивная вёрстка для телефона
- Клавиатурная навигация, видимый фокус, уважение к `prefers-reduced-motion`

## Характеристики

- Чистый HTML/CSS/JavaScript, без сборщиков и фреймворков
- Внешние библиотеки: Chart.js (графики), canvas-confetti (мелкая анимация
  при сохранении смены), Google Identity Services (вход для синхронизации)
- Данные хранятся в `localStorage` браузера; версия схемы данных зашита в
  сохранённый файл, что упрощает совместимость при будущих обновлениях
- Открывается прямым запуском `index.html`, локальный сервер не обязателен

## Структура проекта

```
index.html      ← разметка страницы, подключает стили и скрипты
css/            ← стили, по одному смысловому блоку в файле
js/             ← логика, по одной функции/задаче в файле
```
